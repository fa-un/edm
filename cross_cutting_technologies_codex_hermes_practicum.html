Codex и Hermes Agent: от установки до проверяемого результата

Практика для финансистов: установите Codex и поручайте ему задачи с файлами знакомого проекта.

1. Что называют агентом

Чат-бот — интерфейс для диалога человека с программой.

Модель — вычислительный компонент, который по входным данным формирует выход, например текстовый ответ.

Агент — система, обладающая:

  1. наличием границы между агентом и окружающей средой и внутреннего состояния, отличного от состояния среды;
  2. гомеостазом — набором допустимых и предпочтительных внутренних состояний;
  3. контуром управления — способностью воспринимать состояние среды и действовать так, чтобы поддерживать гомеостаз.

Это критерий минимальной агентности.

Coding agent — агент для работы с кодом и файлами проекта. Harness — среда вокруг модели: инструкции, контекст и инструменты. Codex — пример harness для coding agent.

2. Codex: короткие поручения

Установите Codex CLI и Codex Desktop по инструкции занятия и войдите в свою учётную запись. Дальнейшую настройку поручайте Codex короткими командами.

Если для занятия выдан auth.json, поместите его в каталог .codex домашней папки: Windows — %USERPROFILE%\.codex, macOS/Linux — ~/.codex.

  1. Откройте в Codex знакомый готовый проект.
  2. Попросите Codex: «Установи Hermes Agent по официальной инструкции». Вход подтвердите сами.
  3. В Codex выберите /model → gpt-6-luna. Попросите Codex настроить Hermes на gpt-6-luna.
  4. Введите /init. Откройте AGENTS.md и проверьте описание проекта, структуру папок и главные файлы. При необходимости поправьте инструкции.

3. Доступ к данным

MCP — способ подключить агенту инструменты внешнего сервиса.

Файлы проекта: Codex работает с файлами открытой папки в пределах выданного режима доступа. Доступ агента может распространяться на файлы, браузер и внешние сервисы — в зависимости от включённых инструментов. Telegram MCP подключает Telegram; Google Sheets — через MCP или плагин. Это разные источники и способы доступа.

Поручение для демонстрации: «Прочитай тестовый файл/лист и кратко перечисли факты». Работайте с учебными данными; сначала проверьте ответ по источнику.

4. Hermes в Telegram

Преподаватель показывает двух Hermes-ботов в группе «Сквозные технологии цифровой экономики»: один работает на OpenAI Luna, другой — на StepFun; оба используют репозиторий EDM. Вызовите каждого через @ и задайте короткий вопрос по учебному материалу. Личные сообщения ботам настраиваются отдельно.

5. Если что-то не работает

При ошибке пришлите скриншот в учебный чат и напишите, на каком шаге она возникла.

На занятии как временный тест обсуждали codex --yolo и PowerShell от администратора; в Telegram-чате советовали сначала разобраться с разрешениями. Выбор зависит от конкретной ошибки.

Для тех, у кого локально не получилось установить инструменты, на занятии предложили доступ к виртуальной машине по SSH; на Linux там нужно было только запустить агента.

6. Проверка документа

Сначала поручите Codex: «Установи навыки: https://github.com/strato-space/greek-scholastic и https://github.com/iqdoctor/logika».

Затем: «Примени оба навыка к главному документу моего проекта. Дай короткие замечания с указанием мест; файл не меняй». Прочитайте результат и отметьте разумные замечания.

Для проверки внутренней согласованности попросите: «Сравни разделы и файлы проекта. Найди противоречия в терминах, датах и выводах; укажи оба места. Файлы не меняй».

Для ВКР сначала поручите извлечь из выданного PDF требования в чек-лист, указав страницу источника для каждого пункта. Если страницы представлены сканами, сначала распознайте текст. Затем попросите: «Проверь фрагмент ВКР по чек-листу Финансового университета. Для каждого замечания укажи требование и место в документе. Непроверенное пометь “не проверено”».

Проверьте замечания сами по исходному документу и требованиям. Вывод агента — черновик проверки, не оценка работы.

7. OODA и самоулучшение

OODA: наблюдай → осмысли → реши → действуй. После ошибки запишите, что увидели, какой следующий шаг выбрали и что изменилось.

Codex выполняет поставленные задачи. Hermes может рефлексировать над диалогами и сохранять повторяющиеся уроки в память и навыки: диалог → рефлексия → сохранённое правило → следующая задача → проверка результата. Это не дообучение модели.

8. GitHub

GitHub хранит резервную копию и историю изменений. Зарегистрируйте учётную запись, затем поручите Codex: «Помоги создать private-репозиторий для моего проекта. Перед отправкой покажи список файлов, затем загрузи проект и проверь, что файлы появились».

9. Что показать

Покажите выбранный проект, AGENTS.md, результат проверки навыками и ответ Telegram-бота. Если застряли — приложите скриншот ошибки и укажите шаг.
