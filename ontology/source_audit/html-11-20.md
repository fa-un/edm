## Unit, evidence, source, audience, and modality rules

- One relation row = one explicit source statement at one locator: one paragraph, one labeled table row, or one diagram arrow. Split distinct independently assertable predicates; do not infer pairwise relations from enumerations or synthetic values.
- Include only reusable ontology-relevant domain relations (e.g. reference/mapping, assignment, containment, plan-to-record/event, data provenance, measured-by/dependency). A product function is tracked separately from domain relations.
- `D/C/I/H` = direct/conditional/inference/hypothesis as stated or implied by this course source. It is not independent truth. Source tags: `course` = course-only assertion; `1C` = product/feature citation; `ASCM`, `CIPS`, `HBS`, `Wiley` = cited external material. Unless stated otherwise, audience is student-facing. Modality tags: `model`, `plan`, `forecast`, `record`, `report`, `event`, or `example`; a status/report is not evidence of a physical event.
- Four-way named-source status: **1** verified against independent authoritative primary/owner source; **2** secondary source only; **3** exact method verifiable but primary unavailable/gated; **4** mention does not define a distinct verifiable method. A course exercise or product workflow confirms only what the course/product says, not external validity.
