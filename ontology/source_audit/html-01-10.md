## Scope, counting rule, and evidence boundary

This registry covers the ten student-facing canonical HTML sources listed first in `ontology/source_corpus_manifest.json`, read directly through EOF. Counting grain is one explicit reusable source statement at one paragraph, labeled table row, or diagram arrow. Clearly independent predicates are split only when separable; repeated source statements are retained separately. Exclude standalone definitions, generic UI/task navigation, example-only IDs and values, and unsupported interpretations unless the example explicitly teaches a reusable relation. Do not infer event execution from plans, documents, status, or reports.

A named candidate is one explicitly named model, method, standard, metric, or practice in a source. Four-way verification categories: 1 = verified narrowly against primary/owner source; 2 = secondary source only; 3 = primary source unavailable/gated; 4 = mention does not define a verifiable method. D/C/I/H codes describe the source assertion: direct, contextual/conditional, inferred, or hypothetical. Per-row relation class, source status, modality, and audience are retained below. Course-only assertions are not independently established by their source page. Unless stated otherwise, audience is student; synthetic examples remain synthetic.
