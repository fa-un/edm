# Управление данными предприятия — индекс проекта

Учебно-методические материалы курса «Управление данными предприятия»
(Финансовый университет при Правительстве РФ, направление 38.03.05
«Бизнес-информатика», ОП «Цифровая трансформация управления бизнесом», 3 курс).

Репозиторий содержит нормативную рамку (РПД), развёрнутые планы лекций и
семинаров и практический источник по 1С:ERP 2.5 (производство и ремонты).

**Программа курса и индекс материалов:** [HTML-страница](https://fa-un.github.io/edm/) · [Индекс Markdown](INDEX.md).
**Методические пособия:** ищите в личном кабинете.
**Правила новых материалов и страниц:** [AGENTS.md](AGENTS.md).
**Опубликованная записка:** [Планирование ТОиР в 1С:ERP](https://fa-un.github.io/edm/seminar1_toir_notes.html).
GitHub Pages автоматически обновляется после отправки изменений в `main`.

- 1.1 Концепция; 1.2 НСИ (структура предприятия, рабочие центры, ресурсные спецификации,

- 1.3 Обеспечение материальными ресурсами; 1.4 Планирование потребностей
  (сценарии, план продаж, план производства, анализ потребностей в ресурсах)
- 1.5 Межцеховое планирование (заказы на производство, очередь заказов, график производства)
- 1.6 Управление на уровне цеха (диспетчеризация этапов, пооперационное управление)
- 1.7 Учёт в производстве; 1.8 выпуск без заказов; 1.9–1.11 давальческое сырьё,
  переработка, внутренняя переработка
- 1.12 Затраты и себестоимость; 1.13 Отчётность; 1.14 Частные задачи
  (серийный учёт, ремонтное производство, брак, возвратные отходы, динамическое планирование)

**Раздел 2. Управление ремонтами**
- 2.1 Концепция; 2.2 НСИ (классы и подклассы, виды ремонтов, объекты эксплуатации, узлы, виды дефектов)

- 2.4 Управление ремонтной деятельностью (заказ на ремонт, планирование работ); 2.5 Отчётность
