# Практикум № 1

## Пояснение: что и зачем создаётся

### Сначала — конкретный результат

После Практикума № 1 в учебной базе должны быть готовы условия для работы производства:

- включён функционал производства;
- включены механизмы аналогов, наборов и назначения спецификаций;
- настроено обособленное обеспечение материалов;
- включён контроль производственных операций;
- задан производственный календарь и график работы предприятия;
- включён учет расходов по объектам возникновения затрат.

Иными словами, пользователь пока не создаёт изделие или заказ. Он включает правила, по которым система будет понимать, как планировать, обеспечивать, выполнять и учитывать производство.

### Что изменится на практике

Например, в следующих практикумах система сможет:

```text
создать ресурсную спецификацию
        ↓
определить материалы и операции
        ↓
сформировать заказ на производство
        ↓
проверить обеспечение материалов
        ↓
запланировать выполнение
        ↓
контролировать производственные операции
        ↓
рассчитать затраты и себестоимость
```

Если соответствующая функциональная опция выключена, нужная команда может отсутствовать, а механизм — не работать или работать в упрощённом режиме.

### Функции, которые включаются

| Настройка | Конкретный эффект |
| --- | --- |
| «Использовать производство» | появляются рабочие места, документы и справочники производства |
| «Использовать аналоги материалов» | можно назначать заменяемые материалы |
| «Использовать параметры назначения спецификаций» | система сможет выбирать спецификацию по правилам |
| «Использовать наборы в производстве» | можно использовать составные наборы материалов |
| «Виды технологических операций» | операции получают дополнительные контролируемые параметры |
| «Контроль выполнения операций (ОТК)» | можно контролировать результат операции и возвращать её на доработку |
| «Учет по физическим лицам» | трудозатраты можно связывать с конкретными исполнителями |
| учет постатейных расходов по ОВЗ | расходы можно анализировать по месту их возникновения |

### Почему часть опций выключена

Опция «Разрешить использование интервала планирования “Час”» снимается, потому что учебный пример использует более крупный дневной интервал планирования. Это упрощает работу с графиком производства.

«Контроль выполнения при закрытии заказов производства» также снимается. В учебном сценарии заказ можно закрыть без дополнительного автоматического запрета из-за незавершённых операций.

«Контроль завершения операций при закрытии этапов производства» снимается по той же причине: этапы не должны автоматически блокироваться этим контролем в базовом учебном сценарии.

### Обособленное обеспечение

Задаются два правила:

- при заказе на производство — «по назначению продукции»;
- при заказе в кладовую — «по назначению получателя».

Они определяют, для кого система резервирует или планирует материалы.

Например, материал для полки может быть связан с заказом клиента, а материал, передаваемый в цеховую кладовую, — с конкретным получателем или этапом производства. Это не даёт смешать материалы разных назначений.

### Производственный календарь

Проверяется календарь «Российская Федерация» и заполняется период работы на текущий год. Календарь отвечает на вопрос: в какие даты предприятие работает, а в какие — нет.

На его основе система рассчитывает:

- рабочие и выходные дни;
- доступное время подразделений;
- даты начала и окончания этапов;
- интервалы графика производства.

Если календарь пустой, система может считать все дни недоступными и не сможет корректно построить график.

### Общий вывод

На конкретном уровне Практикум № 1 включает нужные переключатели, правила обеспечения, учет затрат и рабочий календарь. На абстрактном уровне он формирует режим работы производственного контура:

```text
функциональные опции
        ↓
доступные объекты и команды
        ↓
правила планирования, обеспечения и контроля
        ↓
корректная работа следующих практикумов
```

## Подробная детализация пояснений

### «Использовать производство»

Это главный переключатель производственного контура. Он открывает пользователю производственные справочники, рабочие места и документы. Без него следующие практикумы не смогут использовать полноценный функционал производства.

### Аналоги материалов

Разрешают описывать взаимозаменяемые материалы. Например, один материал может быть основным, а другой — допустимой заменой при его отсутствии. Это полезно не для свободной замены пользователем, а для формализованного правила, которое можно согласовать и контролировать.

### Параметры назначения спецификаций

Ресурсная спецификация описывает, как изготовить продукцию. Параметры назначения позволяют выбирать нужную спецификацию по условиям: продукции, характеристике, подразделению или другим правилам.

### Наборы в производстве

Набор объединяет несколько материалов. Если состав определяется спецификацией, система может развернуть набор до компонентов при формировании этапа производства. Это удобно для повторяющегося комплекта материалов.

### Виды технологических операций и ОТК

Вид технологической операции задаёт дополнительные параметры и правила контроля. ОТК позволяет регистрировать результат операции и при необходимости возвращать её на доработку.

### Учет трудозатрат по физическим лицам

Система будет видеть не только общую трудоёмкость, но и конкретного человека, которому относится работа. Это связывает производство с последующим учетом выработки и начислением заработной платы.

### Финансовый результат и календарь

Учет расходов по объектам возникновения затрат показывает, где возник расход: на каком подразделении, участке или другом объекте аналитики. Производственный календарь задаёт временную основу для всех расчетов производства.
