## Презентации ТОиР в текущей ветке

- `assets/downloads/Семинар 1_Драфт 14-10-23.pptx` и `assets/downloads/Семинар 2_Драфт 21-10-23.pptx` — версии 2023 года, а не PDF-драфты 2024 года из подборки.
- В исходных локальных загрузках и прежних LFS-объектах `main` на втором слайде были логин и пароль. Файлы в текущей ветке обезличены: значения в текстовых полях и найденная встроенная строка на изображении заменены на `******`; локальные оригиналы в `~/Downloads` не изменялись.
- После переписывания `main` старые указатели удалены из истории веток `main` и PR #2. Закрытый PR #1 всё ещё хранит `refs/pull/1/head` на старый коммит; старые LFS-объекты могут оставаться в хранилище GitHub. Запрос на удаление старой ссылки PR, кешированных представлений и LFS-объектов отправлен в GitHub Support (тикет #5036103); полная очистка пока не подтверждена. Актуальность учётных данных и их отзыв/ротация не подтверждены.

## Обращение с учётными данными и внешней подборкой

Во всех шести файлах из подборки обнаружены поля логина и/или пароля. Поэтому исходники из облачной папки не скопированы в репозиторий и не получили публичные ссылки из GitHub Pages. Этот каталог хранит только названия, краткие темы и статус сверки; значения учётных данных здесь не приводятся. Если понадобится включить отдельный файл в репозиторий, сначала заменить каждое значение на `******` и проверить видимый слой, текстовый слой, заметки и вложенные изображения.

- Основные материалы по планированию и исполнению ТОиР в репозитории уже представлены HTML-записками и презентациями 2023 года; новые PDF 2024 года — дополнительные источники для сверки, а не готовые замены.
