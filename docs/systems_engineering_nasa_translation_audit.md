## Терминологические решения

- systems engineering — системная инженерия;
- system — система;
- stakeholder — заинтересованная сторона;
- Product Realization — реализация продукта (Product Realization в оригинале; включает создание, приобретение, программирование, повторное использование и интеграцию);
- verification / validation — верификация / валидация;
- SE Engine — «двигатель» системной инженерии; английская метка остаётся на оригинальной схеме;
- iterative / recursive — итеративный / рекурсивный, с разными пояснениями из определения NASA;
- ConOps — концепция операций (ConOps);
- Human Systems Integration (HSI) — интеграция человеческих систем; не сводить к интерфейсу пользователя или эргономике;
- Project Planning and Control (PP&C) — планирование и контроль проекта.
